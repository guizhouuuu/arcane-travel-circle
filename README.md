# 法师传送阵 / Arcane Travel Circle


[下载安装包 v1.2.1](https://github.com/guizhouuuu/arcane-travel-circle/releases/tag/v1.2.1)。在发布页的 Assets 下载 Mod ZIP。

当前版本：**1.2.1**。

在法师塔原版魔法建筑菜单花 **2,000,000 金币**建造一个 3×3 大传送阵。靠近并**右键点击大阵**打开世界地图，左键点击目的地或其他传送阵的标记即可传送。原有站阵上手动开地图的方式也可继续使用。

建造不需要额外材料，立即完成。建成后传送免费、无每日次数限制、不消耗体力。法师菜单仍需通过原版流程解锁。

## 版本与依赖

- 目标及本机程序集基线：PC Stardew Valley **1.6.15 build 24356**，SMAPI **4.5.2**。
- 首版仅支持单人游戏。多人游戏中不启用传送。
- 可与 **NPC Map Locations 3.5.2** 共存；其依赖为可选，不需要安装它才能使用本 Mod。
- 不需要额外安装 Content Patcher 或 Solid Foundations。使用 SMAPI 自带的 Harmony，仅接管法师菜单中小阵条目的购买按钮和悬停文字。
- 当前发布前验证记录见 [TESTING.md](TESTING.md)。编译与离线验证不等于游戏内验收通过。

## 安装与使用

1. 保存并完全退出星露谷。
2. 解压安装包，将其中 `ArcaneTravelCircle` 文件夹放入游戏的 `Mods` 文件夹。不要把源码工程当作安装包。
3. 使用 SMAPI 启动游戏。在法师塔的魔法建筑菜单中购买“法师传送阵”，在农场放置。
4. 靠近已建成传送阵，右键点击阵面打开地图。
5. 选择明确的室外位置并左键点击。危险落点会在附近八格半径内寻找合法位置；找不到时保留原位置并提示原因。

点击地图外、关闭按钮、切换菜单页和 Esc 仍按原版操作。站阵外打开地图时不处理传送点击。移动或拆除建筑使用原版建筑管理菜单。

## 小传送阵网络

- 农场先建成大阵后，进入法师魔法建筑菜单，用原版左右箭头切换到独立的“小型传送阵（带走放置）”卡片，点击“购买”直接领取背包物品，不再打开另一层商店。
- 小阵每个 **200,000 金币**，同一存档**累计限购 10 个**。每次点击购买一个，短时间重复输入会去重；余额不足、背包满和取消菜单不会增加购买计数。
- 小阵为背包物品。手持后点击相邻的可通行室外空地放置，占地 **1×1**；农场内、室内、临时场景和阻挡地块不可放置。
- 右键已放置小阵，打开地图并点击其他大阵或小阵标记互传。小阵只选择已有阵；大阵保留任意地图位置传送。
- 金色标记为大阵，蓝色标记为小阵。位置相近时标记错开并保留连接线；跨区域、无精确映射或屏外目的地放在带地点名的侧栏，可用滚轮查看更多。
- **Ctrl+右键**拾取小阵，搬动不收费，保留原编号和购买计数。购买失败或背包满时不保留扣款。
- 小阵只保存坐标并在地面绘制，不加入物件、地形或建筑碰撞格，不阻挡人物及 NPC 路线。

购买与放置时都要求农场仍有已建成大阵。已放置小阵的移动和互传记录正常保存，重载后恢复。

## 地图覆盖与兼容

城镇、森林、山区、海滩、巴士站、铁路、农场及后山等使用实际 `Data/WorldMap` 位置数据反算落点。同一区域中不同位置的点击可对应不同地块；地图为示意图，不能保证图画中的每个像素都与场景细节完全一致。

沙漠使用集中声明的近似区域投影。秘密森林要求已实际访问过。尚未修复的桥和未解锁地区不能通过落点搜索绕过。地图上的建筑标记只在能找到其确定室外出口时传到门外。

**在农场打开的原版地图只显示山谷区域；其姜岛总览标记没有岛上具体位置数据，首版拒绝将它猜成某个固定岛屿落点。** 不直接选择房间内部、矿洞楼层、山顶和无法可靠解析的标记。扩展地图兼容未作承诺。

详细覆盖表、消歧规则和解锁依据见 [docs/MAP-COVERAGE.md](docs/MAP-COVERAGE.md)。

1.1.0 修复可行走桥面带水属性时被拒绝的问题，补充采石场桥图画到真实桥面的局部连续映射，并扩大公会图标的入口点击范围。已通过真实地图资源离线回归，游戏内点击体验仍待用户确认；未修桥、裸水和栏杆继续拒绝。

落点还需证明能够步行到可用室外出口、沙漠返程巴士或当前源法阵。封闭区域和无法在有限搜索内证实可离开的区域会被保守拒绝；不会为完成传送而放宽安全条件。

NPC Map Locations 的页面、NPC 标记和悬停内容由其自身继续绘制。本 Mod 读取实际 `MapPage.mapBounds` 和映射数据，只在站阵状态处理地图画布内的左键点击，不替换地图页或修改 NPC Mod 文件。实际共同运行的游戏内验收仍应按 [TESTING.md](TESTING.md) 执行。

## 从源码构建

需要 **.NET 8 SDK 8.0.2xx 或更新版本**，以运行构建包的编译分析器；生成的 Mod 仍以游戏使用的 **.NET 6** 为目标。NuGet 构建依赖固定为 `Pathoschild.Stardew.ModBuildConfig 4.4.0`。

```powershell
dotnet build .\ArcaneTravelCircle.csproj -c Release '-p:GamePath=C:\path\to\Stardew Valley'
```

也可使用：

```powershell
.\tools\build.ps1 -GamePath 'C:\path\to\Stardew Valley'
```

默认 `EnableModDeploy=false`，构建不会修改正在使用的 Mods 文件夹。安装 ZIP 输出到工程相邻的 `packages` 文件夹。游戏本体与 SMAPI 程序集不会进入安装包。

离线断言检查：

```powershell
.\tools\build.ps1 -GamePath 'C:\path\to\Stardew Valley' -RunSmokeTests
```

离线检查程序目标为 .NET 6，运行它需要可用的 .NET 6 runtime；这些检查不打开游戏、不读写存档、不安装 Mod。

`assets/circle.png` 是本项目原创的 48×48 透明像素贴图。可选的 `tools/generate-texture.py` 可用 Python + Pillow 重建该文件；正常构建和使用不需要 Python。

## 卸载与存档

大阵使用原版 `Building` 类型和稳定 ID。小阵许可、编号和场景坐标保存在本 Mod 的 JSON 存档数据中，不序列化自定义游戏实体。

升级会保留现有大阵和小阵数据。卸载前先备份存档并拆除所有大阵。小阵物品为自定义保护物品，当前没有一键卸载清理命令；已有小阵物品时，需先清理其存档物品记录或使用安装前备份，直接删除 Mod 可能出现未知物品。已放置小阵在移除 Mod 后不再绘制，也不会留下碰撞格；保留的数据可在重新安装后恢复。

修改或测试存档前保留备份；请使用测试副本验收购买、拆除和保存重载，避免测试消耗正式存档的金币。
